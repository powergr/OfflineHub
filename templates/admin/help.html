❓ Help & Troubleshooting

Plain-language answers for the questions that come up most when running this on-site.

The Basics

What is a "module"?

A module is one piece of content: Wikipedia, a map, the offline chat assistant. Each one is a self-contained folder under C:\OfflineHub\modules\ — installing one downloads it and adds it to the student portal automatically; removing one (from the Modules page) deletes just that folder and nothing else. There's no limit on how many you install beyond your PC's disk space.

What does "hotspot" actually mean here?

Turning on the hotspot makes this PC act like a Wi-Fi router: student phones/laptops/tablets connect to the network name (SSID) and password you set on the Hotspot page, the same way they'd join any other Wi-Fi. No school router, internet connection, or extra hardware is involved — once connected, opening any browser and going to this PC's address (shown on the Hotspot page) reaches the portal. Students never need their own internet access.

If the Hotspot Won't Start

"Administrator rights are required"

Windows only allows starting a Wi-Fi hotspot from an elevated process. Close the app, then right-click OfflineHub.exe (or its shortcut) and choose "Run as administrator", and try again from the Hotspot page.

It fails immediately, or mentions "NO_INTERNET"

This is the single most confusing part of running an "offline" app: Windows' built-in Mobile Hotspot needs this PC to already have some active network connection (Wi-Fi or Ethernet, even one with no real internet behind it) to share from — it's a Windows requirement, not something OfflineHub controls. Connect this PC to any network once (even a phone's hotspot works), then try starting the hotspot again. Students still won't need that connection once the hotspot is running.

It fails with a netsh / "hosted network" error

Some Wi-Fi adapter drivers don't support the older "hosted network" method at all — this is a driver limitation, not something adjustable in software. Open a Command Prompt and run netsh wlan show drivers; if "Hosted network supported" says No, the modern Mobile Hotspot path (see above) is the only one that will work on this hardware.

If a Download Fails

A failed download shows a plain-English reason (not enough disk space, a network error, a corrupted file) and turns the button into Retry — click it to try again; downloads resume from where they left off rather than starting over. If it keeps failing:

  • Check this PC has enough free disk space (large items like maps and the offline assistant need several GB).
  • Check this PC's own internet connection — only needed while downloading, never for students afterward.
  • Try again later — the content is served by Kiwix's free public library, which occasionally has its own outages.
Something Else

The Settings page has an Export Diagnostics button — it zips up the log file, your settings (with passwords removed), and the list of installed modules into one file you can email to whoever's helping you. Logs also live directly at C:\OfflineHub\logs\offlinehub.log if you want to look yourself.
