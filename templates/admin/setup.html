🏫 Welcome to Offline Hub

This wizard sets up your local knowledge server. Once configured, users connect to your Wi-Fi hotspot and open any browser — no internet needed.

ℹ️ Before You Start
  • Hardware: any Windows 10/11 PC works for Wikipedia, Gutenberg, and maps. If you plan to install the offline chat assistant too, budget ~5GB free disk and 8GB+ RAM for the recommended model (the largest option wants 16GB+ RAM — each option on the Assistant tab lists its own requirement).
  • What "hotspot" means: turning it on makes this PC act like a Wi-Fi router — students connect to the network name and password you set on the right, the same as joining any other Wi-Fi. No school network or router involved, and students never need their own internet.
  • It's safe to walk away mid-setup: downloads you start below keep running in the background even if you close this browser tab. Reopening the app brings you right back to this page until you click Finish Setup — nothing you've already downloaded is lost.
